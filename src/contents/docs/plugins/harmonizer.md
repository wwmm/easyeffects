# Harmonizer

The Harmonizer adds two pitch shifted voices to the input. Set the root note and chord, then choose an interval and level for each voice. The dry/wet control balances the original signal with the harmonized signal.

Easy Effects uses the StereoHarm LV2 plugin from Rakarrack Plus. Install Rakarrack Plus to use this effect.
